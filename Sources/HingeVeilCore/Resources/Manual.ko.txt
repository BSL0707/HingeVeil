HingeVeil · 힌지베일 사용 설명서
한국어 · 개발 미리보기 0.1.11

1. 요구 사항과 제한

macOS 14 이상 Apple Silicon용 개발 앱입니다. 실제 효과에는 지원되는 내장 덮개 각도 센서와 내장 화면이 필요합니다. 칩 이름이나 화면 크기만으로 호환을 보장하지 않습니다. 백호 그림 미리보기는 화면 캡처 권한 없이 사용할 수 있습니다. 모든 기종·미션 컨트롤·HDR·외장 화면 구성·장시간 전력 사용을 종합 검증한 상태는 아닙니다.

2. 언어

설정창의 언어에서 시스템 설정 따름·한국어·English를 선택합니다. 시스템 설정 따름은 첫 번째 선호 언어가 한국어이면 한국어, 그 외에는 영어를 사용합니다. 앱 UI·현재 상태 메시지·설명서는 재시작 없이 바뀝니다. macOS 자체 권한 창은 이 선택 대신 시스템의 앱 언어 설정을 따를 수 있습니다.

3. 권한과 최초 실행

다른 덮개 효과 앱은 종료한 뒤 시작하세요. 화면 권한 확인을 누르고 시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음에서 HingeVeil을 허용합니다. 구형 macOS에서는 화면 기록이라는 항목일 수 있습니다. macOS가 안내하면 종료 및 다시 열기를 누릅니다. 앱은 접근성·입력 모니터링·마이크·소리 캡처 권한을 요구하지 않습니다.

로컬 빌드는 임시 서명이며 Developer ID 서명·공증본이 아닙니다. 내려받은 실행파일을 Gatekeeper가 경고하거나 차단할 수 있습니다. Gatekeeper·SIP·시스템 전체 보안 보호를 끄지 마세요. Apple Developer 가입·유료 서명·공증은 이번 소스 업로드 준비에서 제외합니다. 개발 실행파일을 다시 빌드하면 권한을 재연결해야 할 수 있습니다. 필요한 경우에만 HingeVeil의 화면 권한을 대상으로 처리하며 모든 앱·서비스의 권한을 초기화하지 마세요.

4. 미리보기와 실제 사용

미리보기 각도를 움직이면 바탕화면을 캡처하지 않고 백호 그림으로 효과를 봅니다. 이 슬라이더는 실제 덮개의 각도를 제어하지 않습니다.

시작 각도는 85·90·95·100도이며 기본값은 90도입니다. 블러는 네 단계이고 기본값은 2단계입니다. 기존에 저장한 선택은 유지합니다.

실제 덮개 효과를 켜고 덮개를 시작 각도보다 3도 이상 열어 준비합니다. 시작 90도이면 93도 이상 여세요. 그 뒤 내리면 효과가 적용됩니다. 켜기·끄기 선택을 기억하며 권한과 안전 기능이 준비된 경우에만 복원합니다.

30% 접힘 테스트 · 2초를 누르면 실제 바탕화면에 2초간 표시한 뒤 약 0.24초 동안 복귀합니다. 테스트와 실제 효과에는 화면 권한이 필요합니다. 메뉴 막대의 HingeVeil 아이콘으로 설정창을 다시 열 수 있습니다.

5. 시각효과의 동작

제한된 반대 방향 보정·부드러운 윤곽·중앙 및 양옆 블러를 적용합니다. 하단 힌지는 고정하고 위쪽 일부는 화면 안에 다시 끼워 넣지 않고 잘라냅니다. 패널상 세로 확대 상한은 12%이며 무제한 확대하지 않습니다. 블러 강도는 각도 보정 형상을 바꾸지 않습니다.

일반 시작은 효과 없는 첫 프레임 뒤 약 0.18초에 걸쳐 연결됩니다. 일반 종료는 원래 좌표로 돌아가며 약 0.24초 동안 흐려져 사라집니다. 종료 중 다시 닫으면 효과를 이어갑니다. 실제 눈 위치를 추적하지 않으며 화면이 공간에 물리적으로 고정됨을 보장하지 않습니다.

6. 각도를 유지할 때와 안전 제한

예를 들어 32도에서 멈추면 현재 효과는 시작한 시점부터 최대 15초 뒤 해제됩니다. 이 시간은 고정 안전 제한이며 사용자가 변경하는 설정이 아닙니다. 같은 각도에서 곧바로 다시 시작하지 않습니다. 시작 각도보다 3도 이상 열면 다시 준비됩니다. 테스트는 별도로 2초 표시와 약 0.24초 종료 전환을 사용합니다.

7. 화면이 가려졌을 때 탈출

효과 화면을 클릭하거나 Control + Option + Command + Esc를 동시에 누르면 현재 오버레이를 즉시 해제합니다. 메뉴의 효과 즉시 해제도 같습니다. 백그라운드 캡처까지 멈추려면 실제 덮개 효과를 끄거나 앱을 종료하세요.

효과가 표시되는 동안 앱의 메인 처리 루프가 멈추면 별도 안전 감시가 약 3초 뒤 HingeVeil을 종료하도록 설계되어 있습니다. 운영체제나 WindowServer 전체 정지까지 복구를 보장하는 기능은 아닙니다. 필요하면 Command + Option + Esc → HingeVeil → 강제 종료를 사용하세요.

8. 메뉴 막대에 화면 공유가 표시되는 이유

실제 덮개 효과를 켜두면 시작 지연을 줄이기 위해 로컬 ScreenCaptureKit 연결을 유지합니다. 대기 중 최대 15fps, 효과 중 60fps를 요청하고 합성기는 화면의 지원 주사율 범위에서 최대 120Hz를 요청합니다. 덮개를 열고 있거나 현재 오버레이만 해제한 뒤에도 macOS의 화면 캡처·공유 표시가 유지될 수 있습니다. 다른 사람에게 화면을 보내는 뜻은 아닙니다.

실제 덮개 효과를 끄거나 앱을 종료하면 해당 캡처 연결을 중단합니다. 시스템 권한을 취소할 필요는 없습니다. 메모리·전력 사용은 기기·화면·화면 내용·사용 상태에 따라 달라지며 일정한 메모리 사용량을 보장하지 않습니다.

9. 잠자기·잠금·동영상·화면

완전히 닫아 잠자기에 들어가면 효과를 중지합니다. 잠금 화면 위에서 열림 효과는 지원하지 않습니다. 잠금 해제 후 충분히 열어 준비한 뒤 다시 내리세요. 내장 화면에만 적용합니다. 보호된 동영상은 검게 캡처될 수 있으며 HDR·원본 색상과 완전한 일치를 보장하지 않습니다.

10. 개인정보

화면 프레임은 로컬 효과 표시를 위해 메모리에서만 사용합니다. 화면 녹화 파일 저장기·화면 업로드·소리/마이크 캡처·분석 서버·계정·결제·라이선스 서버는 포함하지 않습니다. 언어·각도·블러·켜기 설정은 로컬에 저장합니다. 개발자 진단용 실행 인수를 명시적으로 사용하면 숫자·상태 보고서나 자체 그림 PNG를 저장할 수 있지만 실제 바탕화면 프레임은 저장하지 않습니다. 진단 파일을 공개하기 전에 내용부터 확인하세요.
