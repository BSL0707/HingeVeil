# 화면 권한·재시작·구버전 복구

[English](Permissions.en.md) · [다운로드·설치](../README.ko.md) · [전체 설명서](Manual.ko.md)

## 먼저 확인

HingeVeil 0.1.12는 임시(ad-hoc) 서명 개발판입니다. 이 개선은 권한 상태 갱신과 안내를 보완할 뿐, macOS의 허용을 우회하거나 서명 충돌을 자동 해결하지 않습니다. **‘미확인’은 앱이 현재 허용을 확인하지 못했다는 뜻**이며, 사용자가 허용하지 않았다고 단정하는 메시지가 아닙니다.

## 처음 설치

1. 다른 HingeVeil 복사본과 덮개 효과 앱을 종료하고, 응용 프로그램 폴더의 한 버전만 실행합니다. DMG 안에서 실행하지 마세요.
2. **화면 권한 요청**을 한 번 누릅니다. **설정 열기** → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음(구형 macOS: 화면 기록)에서 HingeVeil을 직접 허용합니다.
3. 시스템이 안내하면 **종료 및 다시 열기**를 선택합니다. 또는 앱의 **권한·재시작 도움말 → 앱 종료**로 종료한 뒤 응용 프로그램에서 다시 엽니다.
4. **권한 다시 확인**으로 ‘화면 권한 확인됨’을 확인한 뒤 실제 덮개 효과를 직접 켭니다.

앱으로 돌아올 때와 앞에 떠 있는 동안 최대 초당 한 번 권한을 읽습니다. 효과 켜기·테스트·권한 다시 확인은 시스템 요청창을 띄우지 않습니다. 요청 버튼도 한 번 실행한 동안 최대 한 번만 시스템 요청을 호출합니다. 거절되거나 이미 요청했다면 설정과 재시작 안내를 사용합니다. 화면 권한을 확인할 수 없게 되면 캡처·효과를 중지하고 자동으로 다시 켜지 않습니다.

## 허용했는데 계속 미확인 / 구버전에서 업데이트

임시 서명이 바뀐 새 빌드는 이전 허용 기록과 충돌할 수 있습니다. 동일한 DMG를 다시 받는 것만으로 서명이 달라지지는 않습니다. 권한 설정과 재시작을 먼저 확인하세요. 창만 닫아서는 앱이 종료되지 않습니다.

계속 실패할 때만 다음 **선택적 수동 복구**를 사용합니다.

1. HingeVeil을 완전히 종료합니다. 다른 복사본도 종료합니다.
2. 본인이 원할 때 터미널에서 아래 명령만 실행합니다. **HingeVeil의 화면 녹화 허용 기록만 초기화**하며 다른 앱의 권한은 대상으로 하지 않습니다.

   ```sh
   tccutil reset ScreenCapture com.bsl0707.hingeveil.preview
   ```

3. 응용 프로그램의 동일한 HingeVeil을 다시 열어 **화면 권한 요청**을 한 번 누르고 직접 허용합니다. 안내되면 종료 및 다시 열기를 선택합니다.

앱이 이 명령을 자동 실행하지 않습니다. `tccutil reset All`, 전체 앱 권한 초기화, TCC 데이터베이스 직접 편집, Gatekeeper/SIP 비활성화나 격리 속성 제거는 하지 마세요. 회사·학교 관리 정책 또는 OS 상태에 따라 수동 복구도 실패할 수 있습니다. 반복 초기화 대신 [오류 제보](https://github.com/BSL0707/HingeVeil/issues)를 해주세요. 진단의 개인 정보는 먼저 가리세요.

## 남아 있는 한계

- 임시 서명이 바뀌는 향후 업데이트에서 재허용·수동 복구가 다시 필요할 수 있습니다. 이 버전은 영구 해결을 보장하지 않습니다.
- Developer ID 서명·Apple 공증은 포함하지 않았습니다. Gatekeeper 최초 실행 차단은 화면 녹화 권한과 별개의 문제입니다. [Apple 실행 안내](https://support.apple.com/ko-kr/102445)
- 전체 기종의 신규 설치·업데이트·OS 권한 동작을 검증한 것은 아닙니다. 자동 테스트는 실제 macOS 권한 허용을 대신하지 않습니다.

화면이 가려지면 **클릭 또는 Control+Option+Command+Esc**로 해제합니다. 캡처까지 중지하려면 실제 효과를 끄거나 앱을 종료하세요.
